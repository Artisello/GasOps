# Step 7 — Advanced KPI Intelligence

KPI operativi defaults to Panoramica; Registro operativo retains the existing Demo / Dati importati tabs. The overview is read-only and never uses demo fixtures, fetches external data, sends inputs to an LLM or stores imported records in a shared database. Use existing dedicated views to load the source data; session data disappear when the session ends. Historical archives included in the repository remain available without credentials.

Three primary proposed operational KPIs: overdue open activities (all dates as-of), mean absolute latest reported SAS estimate (selected month, completed gas days), usable definitive coverage (selected participant and month). Diagnostics: monthly deadline punctuality, next seven days, peak and SAS coverage, public aggregate revised-day share and absolute revisions of comparable pairs only, participant exceptions including missing days. Unavailable input is not zero. Denominator displayed. No official Snam target or composite health score; public aggregate revisions are not participant invoices.

External context deliberately independent of selected month: ENTSOG one point/direction latest physical flow, same-day firm technical utilization and flow minus renomination; GIE AGSI+ Italy stock and source-published fill on same day; Terna / ENTSOG Pearson on complete paired days (experimental timestamp semantics); ACER LNG price and published spread; ACER 2026 Italy BAF (three published metrics), MASE 2025 domestic production, Terna 2025 gross electricity from gas. Source/period/scope/status on each row; no assumptions that external benchmarks are internal performance or contemporaneous. No plots using synthetic values and no invented alerts. Staleness rules are app informational policies, not Snam contractual obligations. Manual imports are labelled declared; historic transcriptions retain linked provenance. The new scorecard exports aggregate numbers, statuses and definitions but no participant identifier/task ID or underlying file. Scope labels from ENTSOG are public API metadata. 

Tests use deterministic fixtures and archive source checks; no new dependency, API key or recurring job. Live source contracts and actual Snam team targets still need validation before operational use. Step 8 is multivariate forecast evaluation; the scorecard does not change forecasts.
