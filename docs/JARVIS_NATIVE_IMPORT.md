# Jarvis native import

Stoccaggi e forniture > Rete Snam > Importazione nativa. One authorized XLSX/ZIP/WKR CSV at a time, cumulative session, source-hash deduplication, no filesystem extraction or shared persistence. No PDF ingestion, no raw uploads committed, no external calls, no formula execution. Explicit consent remains required; the Confidential daily analysis PDF was excluded from integration. Sources are not independently certified for redistribution.

Formats inspected from user-supplied files: annual DatiOperativi 2023–2026 (Storico_G selected fields, original label and update time including suffix, source unit not explicit; 2026 same-slot cross-check against daily workbook corroborated MWh for injection, withdrawal and SAS on 11 slots; do not generalize unit automatically to all years), daily hour tabs G-1/G/G+1/G+2 (MWh columns with labelled day; selected rows), monthly transported gas balances (Jan–Sep definitive, Jan–Nov provisional), WKR forecasts/consuntivo/intraday and semicolon native CSV (zone codes separate from names), qk MY/G WD/DA (signed coefficients, no automatic interpretation), storage Gas Stock including projected future days and separate HS2. Nonselected tabs/metrics not normalized. Original source cell coordinates (sheet, row, metric) and SHA-256 retained. No invented publication times. Missing values omitted; no zero imputation. No automatic forecast or KPI substitution until semantics and publication vintages certified.

Balance reconciliation: all 9 definitive kWh headers declared Sm3 and all 11 provisional Sm3 headers declared kWh in supplied files; numerical cross-check of 7,128 selected pairs found maximum absolute energy difference 0.000005286 GWh (rounding), using 10.57275; selected values only. Runtime validates each file, same period/stage/day/columns and all selected numeric pairs <=0.00002 GWh. Mark conflicting header and inferred units; independent publisher confirmation pending. Different phase values shown by day; overlapping conflicting files suppress delta rather than select arbitrary vintage. No temporal ordering or individual settlement claim. Cross-check is not a correction of the original document.

Limits: 16 MiB compressed per file, 160 MiB expanded per archive, max 500 members, one nested ZIP level, 500k numeric observations/session. User-supplied originals remain outside git. The module does not authenticate upstream source, guarantee every sheet supported or inspect all confidentiality markings. Private storage/long-term warehouse integration and official API contracts remain future work. Tests include synthetic reconciliation and conflicts, WKR CSV and empty UI; local profiling used the original files, not deployed API.
