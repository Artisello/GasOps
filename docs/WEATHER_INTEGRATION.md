# Weather by default

The non-commercial I.G.O.R. demo enables Open-Meteo by default; sidebar opt-out and server environment IGOR_WEATHER_ENABLED=0 disable the shared weather integration. Free hosted API may not be used for commercial deployment; verify provider terms before adopting commercially. Attribution CC BY 4.0, https://open-meteo.com/en/terms. No new paid service.

Shared source acquisition: independent ERA5 history (up to 365 days, seven-day delay) and next seven gas days of weather forecast, mean temperature and city-level HDD base 18 °C (equal-weight Milan/Rome/Naples). Gas-day 06–06, DST-safe existing parser. Cache/session throttle, 6 hours between ordinary attempts and 60 seconds for manual refresh. Preserve historic valid data on failures, no stale or failed weather forecast as current. No automatic weather requests on synthetic or JRC demo workflows. Central refresh includes weather by default; automatic data analyst attempts weather before planning a question. Historical ERA5 available for correlations; future weather only as separately dated forecast evidence. Analyst consent and other restrictions unchanged. Forecast model uses historical HDD default for recent ENTSOG, with seven-day feature lag and explicit no-weather fallback on source failure; historical JRC lab remains offline by default. The existing gas-day weather sector model now runs by default on eligible recent ENTSOG and can reuse shared weather data; Snam annual vintage model already includes its own published HDD, no future ERA5 observations inserted into that model. No assertion that weather improves MAE; empirical comparison and source limitations retained. Live provider not tested in CI.

Market daily and monthly real views both show the current weather outlook; the daily scenario is separate and may be unavailable if demand history is insufficient. Briefings reuse the shared session snapshot and retain weather-only context if the sector model cannot run. AI may cite the precomputed SRG weather scenario only when its input bundle and meteorological acquisition match the current sources.
