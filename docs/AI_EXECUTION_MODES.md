# AI execution modes

The global analysis mode remains deterministic by default. Assistant → Assistente operativo now gates natural-language input and shortcuts when no selected/valid model; no automatic AI activation, provider call or deterministic answer to a free question. Explicit activation button synchronizes the sidebar via a pre-rerun callback. Report locali offers predefined reports without model use even if a provider is selected globally. Analista dati permits explicit local statistics, disables free-text question when AI is inactive, and requires the usual consent for external interpretation. Previously generated responses are historical, never new responses; AI narrative not displayed/exported by the analyst while AI is off. The existing model request budget and source permissions remain unchanged. Workflow required policy rejects requests before execution if AI is not selected; model failure may retain deterministic calculation evidence with explicit warning, never labelled AI. A missing or empty synthesis is treated as failure. No new dependencies, automatic cost, provider credential changes or live deployment verification. Tests cover disabled mode, explicit activation, local reports, and fallback.
