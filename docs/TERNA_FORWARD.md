# Terna anticipatory signals

Terna market Load Forecast (OAuth, market/v1.0/input/forecast-load) and Wind Production Forecast (OAuth, generation/v2.0/wind-production-forecast) added using existing credentials; fixed MSD1 session to avoid mixing markets. Up to 7 gas days/request, D+2 maximum; provider may not offer forward coverage. Strict seven geographic zone coverage for every UTC interval, hourly or quarter-hourly inferred from exact grids. No imputation; contradictory values discarded. Wind lacks offset: ambiguous DST hours rejected; publication date and forecast timestamp are checked, not assumed to prove original availability. Timestamp start-of-interval convention experimental. No assertion that zonal sums equal Terna national total load or that load minus wind is full residual load. No solar forecast endpoint verified; no import forecast yet (published Scheduled Foreign Exchange contract uses private hostname/API-key, do not transmit OAuth token). Capacity and IMCEI are separate next-stage adapters, not implemented here. Source docs: https://developer.terna.it/docs/read/apis_catalog/market/Load_Forecast and https://developer.terna.it/docs/read/apis_catalog/generation/Wind_Production_Forecast.

Mercato > Terna > Previsioni elettriche. Via central refresh too, existing consent and one-minute throttle. Preserve acquired snapshots in session; export and reimport JSON for private archival, max 400 snapshots. No durable shared database or scheduled acquisition. Imported timestamps declared not authenticated. Analyst receives only recent paired forecast evidence. Forecasting Snam > Power–Gas > Previsioni MSD1: existing matched-sample evaluation with target-day predicted load and wind acquired before each original Snam origin 15:00; no future measured data or retrospective backfill accepted. At least 180 training and 30 test days; thus fresh archive cannot immediately demonstrate forecast accuracy. No model promotion, no new service; real API authorization/coverage and contract conventions remain to be tested.
Available individual forward metrics stay visible if the other endpoint fails; proxy and forecast regression require matched complete daily inputs. Existing observed total load minus wind and solar can also be charted and analyzed as a partial residual proxy from matched complete acquisition records.
