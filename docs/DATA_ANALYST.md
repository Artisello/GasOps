# Integrated Data Analyst

Assistente AI → Analista dati. Select up to six available series, a date range and optional public benchmarks and compatible cached Jarvis forecasting results. Ask a specific question. The system calculates period statistics (first/latest, mean, min, max, absolute and relative change) with exact units and coverage counts and same-date descriptive Pearson correlations (only gas-day series, minimum 14 common dates, no inference of causality). No missing values or ambiguous same-date values are filled or averaged. Monthly and annual dates use period starts; ACER dates are publication dates, never joined as gas days. The catalog uses existing JRC/MASE/ACER extracts plus already loaded eligible market bundle, native Jarvis balances, annual G−1 Jarvis, Terna complete observed history/session, AGSI+ Italy, ENTSOG single point. Imports must occur in their original views, same session. Public benchmarks and backtests retain their own dates. No automatic downloads or raw data persistence.

Model receives only computed summaries, not raw files, PDFs, private task/participant registers, credentials or case notes. The app uses the selected compatible reasoner, existing rate/size limits, one structured call; local deterministic output remains available even if model fails. Explicit consent for each remote analysis; GIE and interconnection ENTSOG series excluded from remote interpretation. Users must verify rights before transmitting other public-derived aggregates and avoid sensitive questions; an imported file declaration is not proof of rights. Citation IDs are validated against the actual computed evidence. This is not a numerical fact-check of every generated sentence. No user-generated SQL/Python or autonomous actions. Fixed calculations, not a general-purpose arbitrary query engine. No live AI credential tests, source license reassessment or new paid service. Export evidence/answer JSON and clear session-local result. No model selection or activation changes.
