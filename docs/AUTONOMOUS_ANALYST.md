# Autonomous data analyst

Assistente AI > Analista dati > Automatica (AI). Available only when an explicitly selected model is active. Manual analysis is unchanged. A remote provider requires consent before transmitting even the question or metadata. Restricted series (as labelled in the existing catalog) are excluded from remote catalog and calculations. Metadata contains IDs, scope, unit, source and coverage, not raw data. Bound the catalog to 48 entries, prioritizing lexical matches and non-coefficient series; omissions are disclosed, manual selection remains available. No implicit source downloads.

Two bounded provider calls at most, using existing quota and credential handling: a structured selection of tools, dates and IDs; then interpretation of computed evidence. Local validation rejects unknown keys, IDs, tools, future dates and inconsistent plans before execution. An empty plan means no suitable analysis, no arbitrary fallback. Maximum six series and four tools per question. Selected benchmark/forecast facts retain own periods, only matching current cached backtests. No new model training or forecast generation.

Tools: summary, Pearson common gas-day correlation (>=14 pairs, noncausal), linear calendar-day slope (>=14 gas-day observations, no imputation), dispersion (sample SD, median, quartiles/IQR, >=14 observations), provisional vs final native Jarvis comparisons (identical aggregate metric, scope and unit, exact same dates, not cash flow), selected benchmark and forecast evidence. The planner is not free-form SQL/Python; no writes or external actions. Incomplete inputs or incompatible tools are reported. Existing statistics supply lineage; calculated IDs are validated in the model response. Not a fact check of every generated sentence or proof of causal relevance. No live provider validation. Synthetic tests cover allowlisting, calculations and UI consent. Preserve previous restrictions and privacy of the public prototype.
