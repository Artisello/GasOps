Market > Laboratorio previsionale. Separate from production baseline, existing weather scenario and AI briefing. JRC ENaGaD historical archive (last 730 days) available without network or keys; recent ENTSOG SRG target must already be loaded in market view. Do not merge these distinct scopes. JRC projections are historical illustrations, not today's forecast.

Three fixed models: same-weekday naive using target lag 7 or 14 so it precedes reference by >=2 days; calendar + autoregressive Ridge; multivariate Ridge adds three lagged sector series, optional HDD / AGSI+ IT stocks / selected ENTSOG point flow / Terna thermal, wind, photovoltaic or load from session. Up to 3 session covariates plus consented Open-Meteo ERA5 (noncommercial demo). No new credentials, dependencies, paid model calls or auto acquisition except explicitly requested weather. Feature table shows ranges, units and scope. 14-day Terna/31-day point histories usually cannot meet 45-training + 28-day validation requirement, and are rejected rather than silently omitted. No forward fill or use of later acquisitions to claim known vintages. Longer historical exports or recurring acquisition needed in Step 9. Source data final/revised, historical publication vintages unavailable.

Direct horizons 1, 3, 7 gas days. Reference R, target R+h; gas features dated <=R-2, external <=R-7; train labels dated <=R-2. These are modelling assumptions, not verified release timelines. UTC/Rome-aligned source adapters, exact daily calendar reindexing; given R train on common complete rows only, scaling fit on train, fixed Ridge alpha=10, no hyperparameter tuning. Last 28 calendar references with at least 14 comparable test dates and 45 training rows each. MAE, RMSE, bias (prediction minus actual), WAPE common denominators. No model promotion or claims of true historical ex-ante skill. Historical measured covariates can be revised after their nominal dates. Actual source availability and interval semantics are not certified.

Forecast for one selected horizon from reference last observed +2 days (capped at active gas day for current SRG). Refuse if features missing. Descriptive 10–90% residual-quantile band if >=20 backtest records, not calibrated prediction interval. Same reference for all models, no recursive use of forecast targets. Export rows with model train end and source fingerprint. Session-only, no settlement changes, no automated actions.
